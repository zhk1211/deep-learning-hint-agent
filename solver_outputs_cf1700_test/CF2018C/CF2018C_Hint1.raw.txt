So the subtree contains at least one node at each depth in [depth(v), max_depth_subtree(v)]. Therefore, the condition for v to have a node at depth D is exactly: depth(v) <= D <= max_depth_subtree(v).
    // This is a crucial observation! Because the tree is connected and we consider the subtree rooted at v, the depths of nodes in that subtree might not cover all integers between depth(v) and max_depth if there are multiple branches? But wait: the path from v to the deepest node is a single path. That path has nodes at every depth from depth(v) to max_depth. So those depths are definitely present. So for any D in that range, there is at least one node at depth D (the one on that path). So the condition is indeed sufficient and necessary.
