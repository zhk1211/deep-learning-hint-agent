You are solving a Codeforces problem.

=== PROBLEM STATEMENT ===
Description
You are given $ n $ points $ (x_i, y_i) $ on a 2D plane, where $ n $ is even. Select $ \tfrac{n}{2} $ disjoint pairs $ (a_i, b_i) $ to maximize the sum of Manhattan distances between points in pairs. In other words, maximize
$$ \sum_{i=1}^{\frac n2} |x_{a_i} - x_{b_i}| + |y_{a_i} - y_{b_i}|. $$

Input Format
Each test contains multiple test cases. The first line contains the number of test cases $ t $ ( $ 1 \le t \le 10^4 $ ). The description of the test cases follows.

The first line of each test case contains a single even integer $ n $ ( $ 2 \leq n \leq 2 \cdot 10^5 $ ) — the number of points.

The $ i $ -th of the next $ n $ lines contains two integers $ x_i $ and $ y_i $ ( $ -10^6 \le x_i, y_i \le 10^6 $ ) — the coordinates of the $ i $ -th point.

It is guaranteed that the sum of $ n $ over all test cases does not exceed $ 2 \cdot 10^5 $ .

Output Format
For each test case, output $ \tfrac{n}{2} $ lines, the $ i $ -th line containing two integers $ a_i $ and $ b_i $ — the indices of points in the $ i $ -th pair.

If there are multiple solutions, print any of them.

Note
In the first test case, an optimal solution is to select the pairs $ (1, 4) $ and $ (2, 3) $ , which achieves a distance sum of $ 5 + 3 = 8 $ .

In the second test case, an optimal solution is to select the pairs $ (1, 8) $ , $ (9, 10) $ , $ (5, 7) $ , $ (2, 3) $ , $ (4, 6) $ , which achieves a distance sum of $ 4 + 7 + 10 + 5 + 7 = 33 $ .

2122C - Manhattan Pairs
Let's begin by considering the 1D version of the problem.
In one dimension, the optimal strategy is to pair the smallest $$$\tfrac{n}{2}$$$ values with the largest $$$\tfrac{n}{2}$$$ values.
Now, let's move to the 2D case. The Manhattan distance is the independent sum of the contributions from the $$$x$$$-coordinates and the $$$y$$$-coordinates. Therefore, if we find a matching that is optimal independently for both the $$$x$$$- and $$$y$$$-coordinates, it will also be optimal in 2D.
To achieve this, partition the set of points in two different ways:
Let $$$X_l$$$ and $$$X_r$$$ be the sets of points with the smallest and largest $$$\tfrac{n}{2}$$$ $$$x$$$-coordinates, respectively.
Let $$$Y_l$$$ and $$$Y_r$$$ be the sets of points with the smallest and largest $$$\tfrac{n}{2}$$$ $$$y$$$-coordinates, respectively.
A pairing will be optimal in both dimensions if:
each point in $$$X_l$$$ is paired with a point in $$$X_r$$$,
each point in $$$Y_l$$$ is paired with a point in $$$Y_r$$$.
To satisfy both conditions simultaneously, we can pair:
each point in $$$X_l \cap Y_l$$$ with a point in $$$X_r \cap Y_r$$$,
each point in $$$X_l \cap Y_r$$$ with a point in $$$X_r \cap Y_l$$$.
Let $$$a$$$, $$$b$$$, $$$c$$$, $$$d$$$ denote the sizes of these four groups, respectively. Note that they are disjoint. Then, we have:
$$$a + c = b + d$$$, because $$$|X_l| = |X_r|$$$,
$$$a + d = b + c$$$, because $$$|Y_l| = |Y_r|$$$.
Adding these equations up yields $$$a = b$$$ and $$$c = d$$$, so such a pairing is always possible.
