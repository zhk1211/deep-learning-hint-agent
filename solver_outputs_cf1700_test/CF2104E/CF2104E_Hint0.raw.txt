    // Let's analyze the NFA. States are positions 0..n. Transitions: from i, on c, go to j+1 for all j such that s[j] = c and j >= i. This is equivalent to: from i, on c, we can go to any state k such that k-1 is an occurrence of c and k-1 >= i. So the set of next states from i is { occ+1 | occ in Occ[c], occ >= i }.
    // Now, if we have a set of states S, the set of next states on c is the union over i in S of { occ+1 | occ in Occ[c], occ >= i }. Since Occ[c] is sorted, for each i, the set is a suffix of Occ[c] (shifted by 1). The union of suffixes from different i is just the suffix starting from the minimum i in S. Because if i1 < i2, the suffix from i1 contains the suffix from i2. So the union is exactly { occ+1 | occ in Occ[c], occ >= min(S) }. Therefore, the set of next states depends ONLY on the minimum element of S! That's a crucial observation.
    // Let's check: S is a set of states. min(S) = the smallest position. For any i in S, i >= min(S). The set of occurrences >= i is a subset of occurrences >= min(S). So the union over i in S of occurrences >= i is exactly the occurrences >= min(S). Therefore, the new set of states is exactly { occ+1 | occ in Occ[c], occ >= min(S) }.

Not necessarily: if min(S) has an occurrence, then for any i > min(S), the first occurrence >= i might be later or the same. But the union of all possible next states is the set of all occurrences >= min(S). So if there is at least one occurrence >= min(S), then the new set is non-empty.
